# business-insight-agent
# 🤖 AI Decision-Making Agent with Trust Evaluation

This project showcases an AI Agent designed to assist decision-makers by analyzing their campaign, sales, and performance data. It features two distinct agent personalities to evaluate how explanation style influences trust in AI systems.

## 💡 Project Goals

- Help decision-makers understand the return on investment (ROI) from their business activities.
- Provide tailored AI-generated insights via two personas:
  - **Business-Oriented Agent**: Offers detailed and structured analysis with clear justifications.
  - **Generalist Agent**: Delivers simplified responses to focus on ease of use and perceived usability.
- Evaluate which factors most influence users' **trust** in AI-based recommendations.

## 🧠 Technologies Used

- Python
- Streamlit (for user interface)
- OpenAI API + Mistrall  (LLM backend)
- Pandas & NumPy (data handling)
- Scikit-learn (evaluation & analysis)
- Matplotlib / Plotly (visualization)

## 🧪 Experimental Design

This project aims to analyze:
- Trust perception across different AI communication styles.
- The impact of explanation depth, tone, and accuracy on user reliance.
- Business user behavior in response to actionable AI insights.
